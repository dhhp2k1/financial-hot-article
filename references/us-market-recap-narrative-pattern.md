# 美股隔夜复盘文章 — 叙事模式记录

## 场景

写作对象：美股隔夜行情（非农/Crash事件 → 周五暴跌纳指4.18%）
用户反馈：初稿"太简单" → 要求2000字以上 + 叙事清晰

## 初稿问题诊断

初稿只做了：
- 三大指数涨跌幅 ✓
- 个股数据 ✓
- 非农数据 ✓
- 板块轮动 ✓

但用户说「太简单」——缺了什么：

| 缺失项 | 为什么重要 |
|--------|-----------|
| 时间线递进（周三→周四→周五） | 让读者理解暴跌不是凭空出现的——周四博通已崩、道指已创新高，分歧已在 |
| 因果链叙事 | 非农→加息预期→美债收益率飙升→科技股DCF承压→程序化止损→连锁踩踏 |
| 跨资产覆盖（美债、黄金、原油、比特币） | 体现这是一次系统性重定价，不是板块问题 |
| 分析师/机构原话 | 增加叙事层次，避免数据枯燥 |
| 前瞻锚点（下周五CPI） | 给读者"接下来看什么"，收束全文 |
| 个股成交量和盘中细节 | 如NVDA成交量2.15亿股（日均两倍），让数字有画面感 |
| 跌幅排比/对比 | 如「Meta从周初640跌至593」「MSFT两日累跌5%」——体现趋势延续性 |

## 结构模板

```
01 宏观催化（非农/CPI/美联储）
   - 数据全貌 + 市场预期偏差值
   - 利率/政策路径推论（FedWatch概率变化）
   - 为何这只导火索能引爆（估值背景铺垫）

02 板块深挖（半导体/科技七巨头）
   - 时间线：周三财报→周四分歧→周五恐慌
   - 核心个股逐个梳理（≥5只）
   - 每只标的：涨跌幅 + 累计跌幅；成交量异动只在有叙事意义时写（SKILL.md 1.3、8.3）
   - 交易行为描述（如程序化抛售）只写有报道出处的内容，不自行推测

03 跨资产联动
   - 美债收益率曲线变化
   - 黄金/原油/比特币/汇率同步反应
   - 中概股表现
   - 解释逻辑链：为什么各类资产同步动

04 前瞻锚点
   - 下个关键数据/事件
   - 市场定价概率
   - 以事实性日历收尾（SKILL.md 8.6），不写“如果X则……反之则……”的双情景
```

## 字数分配参考

| 节 | 建议字数 | 说明 |
|----|---------|------|
| 01 宏观催化 | 400-600字 | 数据展开 + 预期偏差 + 政策推论 |

| 03 跨资产 | 300-500字 | 各资产联动 + 逻辑链 |
| 04 前瞻 | 200-300字 | 锚定收束 |
| 总计 | 1500-2200字 | |

## 数据来源优先级（美股复盘）

1. **VT get_market_data (yfinance)** — 美股OHLCV，精度最高
2. **VT web_search** — 中文关键词搜财新/东方财富，英文关键词搜CNN/Reuters/Bloomberg
3. **VT read_url** — 获取新闻全文，提取分析师引语和细节数据
4. **三角验证**：同一数据从中文+英文来源各确认一次，不一致时以英文一手信源为准

## 引语使用

每个分析师/媒体引语必须有来源和日期，格式：
> CNN评论指出，「...」（6月5日）
> Axios援引分析师观点称，「...」

不要写「分析人士认为」「有市场观点指出」——这些等于没来源。
