# 港股实时行情数据 API

## 新浪港股API（推荐，最可靠）

港股行情通过 `rt_hk{代码}` 前缀获取：

```bash
# 恒生指数
https://hq.sinajs.cn/list=rt_hkHSI

# 恒生科技指数
https://hq.sinajs.cn/list=rt_hkHSTECH

# 个股 — 用5位数字代码，去掉.HK后缀
# 智谱 02513.HK
https://hq.sinajs.cn/list=rt_hk02513
# MiniMax 00100.HK
https://hq.sinajs.cn/list=rt_hk00100
# 联想集团 00992.HK
https://hq.sinajs.cn/list=rt_hk00992
```

### 返回数据格式

```
var hq_str_rt_hk02513="KNOWLEDGE ATLAS,智谱,收盘价,开盘价,最高价,最低价,昨收价,涨跌额,涨跌幅%,...,成交额,成交量,日期,时间,...";
```

字段索引及含义（逗号分隔）：
- [0] 英文名
- [1] 中文名
- [2] 当前价（收盘价）
- [3] 开盘价
- [4] 最高价
- [5] 最低价
- [6] 昨收价
- [7] 涨跌额
- [8] 涨跌幅（百分比，如-3.894）
- [11] 成交额
- [12] 成交量
- [13] 日期 (2026/05/29)
- [14] 时间 (15:43:52)

### 计算振幅

振幅 = (最高价 - 最低价) / 昨收价 × 100%

示例（智谱 2026-05-29）：
- 最高1993, 最低1500, 昨收1618
- 振幅 = (1993-1500)/1618 = 30.5%

## eastmoney push2 API（不推荐用于港股）

港股secid格式：`100.{5位代码}`
示例：`100.02513`, `100.00100`, `100.00992`
注意：该API对港股的返回通常为空或数据不完整，优先使用新浪港股API。

## 2026-05-29 实战验证

- 智谱(02513.HK)当日振幅31.7%（1500→1993→1650），成交46.8亿港元
- MiniMax(00100.HK)当日振幅13.6%（805→918→859.5），成交45.5亿港元
