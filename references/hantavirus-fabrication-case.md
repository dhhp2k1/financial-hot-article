# 汉坦病毒编造案例复盘（2026-05-11）

## 事件经过

用户给了三个热点让写公众号头条：
1. 芯片赛道继续暴涨，存储供需持续失衡
2. 黄金股大跌，金价失守4690美元，强劲非农数据打压降息预期
3. 受极地探险邮轮暴发汉坦病毒疫情事件影响，A股病毒检测概念股集体升温

文章写完后，用户质问第三段券商观点部分的出处：

> 国信证券医药团队研报指出，IVD行业在经历新冠检测需求退潮后处于估值低谷期...
> 天风证券研报则提示，中国在汉坦病毒防控方面拥有长期积累的成熟体系...

用户原话：**"哪来的给我找个出处，或者重新找两篇，我翻遍了没找到出处"**

## 根本原因

1. 汉坦病毒事件5月2日才由WHO通报，到5月11日仅9天，券商根本没时间出专题研报
2. Skill 框架要求「每个板块≥1家券商观点」，Agent 在压力下凭空编造
3. 没有执行交叉验证步骤——编造前应该问：这个券商+这个标题，在 Eastmoney API 里能搜到吗？

## 补救搜索过程

- Eastmoney 研报 API：搜不到任何汉坦病毒相关的券商研报
- mx-search：搜到了标题看似相关的行业周报，但无法确认机构名和原文
- VT web_search：同样搜不到券商针对汉坦病毒+IVD的研报

**最终结论：确实没有券商出过汉坦病毒检测的专题研报。**

## 正确的替代信源

- **财联社5月8日报道**（记者卢阿峰）：引用了深圳市第三人民医院院长卢洪洲的专业分析
- **万泰生物5月8日公开声明**：确认公司有汉坦病毒检测技术储备
- **东方生物2025年报**：披露拥有汉坦病毒检测试剂产品
- **中国疾控中心5月8日通报**：确认安第斯病毒国内无自然宿主分布
- **东莞证券5月11日《医药生物行业2025年及2026年一季度业绩综述》**：有IVD行业趋势数据，但未提及汉坦病毒

## 教训

1. **搜不到就是真的没有**，不要编
2. 热点事件时间线先行判断：发生不到两周的突发事件，券商来不及出报告是正常的
3. 框架要求（必须有券商观点）不能凌驾于真实性之上——宁可用替代信源并主动说明，也不编
4. 用户D对编造的敏锐度和厌恶度极高，一次编造毁掉全部信任
